# Informativa sulla privacy

All-in-One Histeon Traghetto (aiohtraghetto, app Google «AIOWP_Traghetto») · aggiornata il 20 novembre 2026

## Dati a cui accede

Quando l'utente collega il proprio account Google, il programma riceve il permesso di leggere e scrivere file nel suo Google Drive. Lo usa solo per:

- caricare nel Drive le copie di backup dei siti WordPress scelte dall'utente;
- elencare, scaricare ed eliminare quelle copie quando l'utente lo chiede.

## Dove restano i dati

Il programma funziona sul computer dell'utente. Il token di accesso di Google resta salvato su quel computer. I file passano direttamente tra il computer e Google Drive. Nessun server dello sviluppatore li riceve, li conserva o li analizza.

## Condivisione

I dati ottenuti dalle API di Google non vengono venduti, ceduti a terzi, usati per pubblicità né per addestrare modelli di intelligenza artificiale. L'uso di questi dati rispetta le [norme sui dati utente dei servizi API di Google](https://developers.google.com/terms/api-services-user-data-policy), compresi i requisiti di uso limitato.

## Come togliere l'accesso

Il permesso si revoca da [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Per cancellare anche il token salvato sul computer basta eliminare il collegamento a Google Drive nelle impostazioni del programma.

## Contatti

Per domande si può aprire una segnalazione nelle [issue di questo repository](https://github.com/Seventhose/histeon-aiohtraghetto/issues).

## Privacy policy (English)

When the user connects a Google account, All-in-One Histeon Traghetto (Google app "AIOWP_Traghetto") gets permission to read and write files in the user's Google Drive. It uses it only to upload the WordPress backups the user picks, and to list, download and delete them on request.

The program runs on the user's computer. The Google access token stays on that computer and files travel directly between it and Google Drive. No developer server receives, stores or analyses them.

Data obtained from Google APIs is never sold, shared with third parties, used for advertising or used to train AI models. Its use complies with the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

Access can be revoked at [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Questions: open an [issue in this repository](https://github.com/Seventhose/histeon-aiohtraghetto/issues).
